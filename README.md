# Andrey Reshetnikov — Portfolio (React + TypeScript + Vite)

Одностраничный сайт-портфолио, перенесённый с финального HTML на React + TypeScript (Vite).
Все изображения (портрет, работы, логотипы брендов) вынесены в отдельные файлы в `src/assets`
и бандлятся Vite. Двуязычность RU/EN — через React-контекст, выбор сохраняется в `localStorage`
(по умолчанию английский).

## Быстрый старт

```bash
npm install       # установка зависимостей
npm run dev       # локальный сервер (http://localhost:5173)
npm run build     # прод-сборка в папку dist/
npm run preview   # предпросмотр собранной версии
```

Для сборки нужен Node.js 18+.

## Структура

```
src/
  main.tsx              — точка входа (оборачивает App в LangProvider)
  App.tsx               — сборка секций
  i18n.tsx              — контекст языка RU/EN
  styles/global.css     — все стили (перенесены из HTML без изменений)
  data/content.ts       — весь контент: работы, образование, опыт, навыки,
                          логотипы брендов (двуязычные строки) + импорты картинок
  hooks/
    useHeroSplit.ts     — анимация разлёта имени + всплытие About при скролле
    useDrift.ts         — «плывущие» карточки работ и кружки у портрета
  components/
    Nav, Hero, About, Education, Experience, Brands (бегущая строка),
    Works, Gallery, Contact, Timeline, T (рендер двуязычных строк с разметкой)
  assets/
    portrait.jpg
    brands/             — 20 логотипов брендов
    works/              — 26 изображений проектов
```

## Заметки по коду

- Строки с инлайн-разметкой (заголовки с `<br>`, уровни языков со `<span>`) рендерятся
  через компонент `T` (dangerouslySetInnerHTML) — контент статический и собственный.
- Индивидуальные размеры логотипов в ленте заданы CSS-классами (`lg`, `sm`, `xl12` и т.д.),
  они хранятся в `content.ts` рядом с каждым логотипом.
- Бегущая строка бесшовная: один трек с двумя одинаковыми группами, сдвиг на -50%.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- `base: './'` в `vite.config.ts` — сборка работает и из подпапки, и при открытии файла.

# Как выложить сайт в интернет (пошагово)

Ниже — полный путь от собранного проекта до работающего адреса. Пример на **Cloudflare Pages** —
это самый удобный вариант, чтобы сайт быстро открывался **и в России, и за рубежом** (см. раздел
про хостинг ниже — там объясняется почему).

## Вариант А. Cloudflare Pages + GitHub (рекомендуется)

Плюс: при каждом `git push` сайт автоматически пересобирается и обновляется.

1. **Установи Git и Node.js** (если ещё нет): https://git-scm.com и https://nodejs.org (LTS).
2. **Создай репозиторий на GitHub.** Зарегистрируйся на https://github.com → New repository →
   назови, например, `portfolio` → Create.
3. **Залей проект в репозиторий.** В папке проекта выполни:
   ```bash
   git init
   git add .
   git commit -m "Portfolio"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/portfolio.git
   git push -u origin main
   ```
4. **Зарегистрируйся на Cloudflare** — https://dash.cloudflare.com/sign-up (бесплатно).
5. В панели: **Workers & Pages → Create → Pages → Connect to Git** → выбери свой репозиторий.
6. **Настрой сборку:**
   - Framework preset: **Vite**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Нажми **Save and Deploy**.
7. Через 1–2 минуты сайт будет доступен по адресу вида `portfolio.pages.dev`.

## Вариант Б. Без GitHub, вручную (Cloudflare Wrangler)

Если не хочешь возиться с Git:

1. Собери проект локально: `npm install && npm run build` (появится папка `dist`).
2. Установи загрузчик: `npm install -g wrangler`.
3. `wrangler login` (откроется браузер, подтверди).
4. `wrangler pages deploy dist` — папка загрузится, вернётся ссылка на сайт.

## Вариант В. Netlify (тоже просто)

1. Собери проект: `npm run build`.
2. Зайди на https://app.netlify.com → **Add new site → Deploy manually**.
3. Перетащи папку `dist` в окно браузера. Готово — сайт получит адрес `*.netlify.app`.
   (Netlify тоже можно связать с GitHub для автосборки, как в варианте А.)

# Домен и хостинг: чтобы работало и в России, и за рубежом

## Хостинг

Сайт статический (после сборки — просто HTML/CSS/JS и картинки), поэтому «настоящий» сервер
не нужен — подойдёт бесплатный статический хостинг с раздачей через CDN (сеть серверов по всему миру):

- **Cloudflare Pages** — рекомендую в первую очередь. Бесплатный тариф, очень быстрый CDN
  с точками присутствия в том числе рядом с Россией, стабильно открывается внутри РФ.
- **Netlify** и **Vercel** — тоже отличные и бесплатные, но у них иногда бывают перебои с
  доступностью из России без VPN. Для аудитории в РФ Cloudflare надёжнее.
- **Российский вариант** (если основная аудитория в РФ и важна максимальная стабильность внутри
  страны): **Timeweb** или **Selectel** — можно положить папку `dist` на обычный виртуальный
  хостинг. Такой сайт гарантированно открывается в РФ, но за рубежом может грузиться чуть медленнее.

Практичный компромисс: **Cloudflare Pages** покрывает и РФ, и заграницу без плясок с VPN.

## Домен

Домен (имя сайта) покупается отдельно от хостинга и стоит примерно 300–1500 ₽/год в зависимости
от зоны.

- **Зона `.ru`** — если аудитория в основном российская: регистрируй у российского регистратора
  (обычно требуется, и это надёжнее для РФ): **reg.ru**, **timeweb.com**, **nic.ru**.
- **Зоны `.com`, `.design`, `.me`** — универсально, хорошо и в РФ, и за рубежом. Можно купить у
  того же **reg.ru** или у международных **Namecheap** / **Cloudflare Registrar**
  (у Cloudflare цены без наценки, но оплата картой иностранного банка).

Совет: для дизайнера-портфолио хорошо смотрится `имя.design` или короткий `.com`.

## Как привязать свой домен к сайту (на примере Cloudflare Pages)

1. Купи домен у любого регистратора выше.
2. В Cloudflare: **Workers & Pages → твой проект → Custom domains → Set up a custom domain** →
   введи домен.
3. Cloudflare покажет **NS-серверы** (или CNAME-запись). В панели регистратора, где куплен домен,
   пропиши их (раздел «DNS» или «Управление доменом»).
4. Подожди от 10 минут до нескольких часов — домен заработает, HTTPS-сертификат Cloudflare
   выпустит автоматически.

Если домен куплен прямо в **Cloudflare Registrar**, шаг с NS не нужен — всё привязывается в один клик.
